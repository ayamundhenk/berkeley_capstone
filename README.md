## RF-Based Drone Detection and Classification Using Deep Learning
### Overview
The growth of consumer and commercial unmanned aerial vehicles (UAVs) creates growing security and airspace managemnt challenges.  These challeanges are magnified in restricted or sensitive environments.  This project aims to build a machine learning model that detects the presenece of a drone and classifies its type baserd on the radio frequency (RF) signals without relying on cameras, radar hardware, or GPS.
### Data
The main data sets will be the DroneRF dataset - this is an RF-based collection of dron signals recorded across multiple operating modes include: idle, hovering, flying and video recording.  The data is captured from three differnt drone models alognsige a noisy RF background with no drones present.  This IQ signal data is well-suited for time-series and spectrogram-based ML approaches.  As another source, the CardRF dataset provides RF signals collected from UAV controllers, UAVs, Bluetooth, and Wi-Fi devices.  This dataset is collected at visual line-of-sight and beyond-line-of-sight condidtions spanning over 65GB.  Combined, these datasets provde labeled eexamples of drone presence/absence across varied signal conditions and levels of noise.
### Techniques
As I learn more about machine learning techniques, I may adjust my candidate techniques listed below.
1. Deep Learning - Convolutional Neural Network (CNN) on Spectrograms: Convert raw IQ signals into spectrograms using Short-Time Fourier Transform (STFT), then CNN can identify patterns and feautures in the frequency domain corresponding to each type of drone using by its unique spectral signature.
2. Deep Learning - LSTM / Recurrent Neural Network: Can capture temporal patterns in signal behavior across operating modes (i.e. hovering, flying, grounded)
3. Supervised Learning - Multi-class Classification with SNR Robustness Testing:  Evaluate across varying signal-to-noise ratio (SNR) condition to assess real-world reliability (this is critical because detecting UAVs is challenge with UAV controllers, Bluetooth, and Wi-Fi all sharing the same 2.4GHz band).
